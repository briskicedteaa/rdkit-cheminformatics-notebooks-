RDKit

A collection of notebooks documenting my process of learning RDKit through small, focused exercises.

Each notebook covers one topic and builds on the previous one, so instead of relearning everything from scratch, I can reuse code and workflows in future projects.

Topics

* Parsing molecular datasets
* Molecular descriptors
* Molecular fingerprints
* Tanimoto similarity
* SMARTS
* Molecular standardization
* Murcko scaffolds
* Maximum Common Substructure (MCS)
* Molecule visualization
* Capstone project

Most notebooks use ChEMBL datasets and are written in Python using RDKit.

Learning Resources

Most examples and reference material came from:

* RDKit Cookbook
* RDKit documentation
* suneelbvs/RDKit_Tutorials
* Additional community blogs and tutorials when adapting workflows or troubleshooting specific problems
